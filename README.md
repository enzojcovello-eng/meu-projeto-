# Troféus

Site para marcar as conquistas que você já tem nos seus jogos, com conta própria e vínculo opcional com a Steam.

- `site/`: o site (HTML + JavaScript, sem servidor próprio).
- `supabase/schema.sql`: banco de dados, regras de segurança e os 88 troféus do Rocket League.
- `supabase/functions/steam-sync/`: função que busca jogos e conquistas na Steam.
- `GUIA-DE-INSTALACAO.md`: passo a passo para colocar no ar.
- `conquistas-rocket-league.html`: a versão antiga, de um arquivo só, que salva no navegador.
